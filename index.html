プロジェクトビューのAssetsフォルダ-> Scenesフォルダ-> Kanseiをダブルクリック
画面上部の再生ボタン「▶」を押してゲームを実行してみよう

ゲームを終了するときは「▶」をもう一度押してゲーム終了

プレイヤーを描画しよう

プロジェクトビューのAssetsフォルダ -> Sceneフォルダ -> MainSceneをダブルクリック
ヒエラルキービューのPlayerを左クリックで選択
右側インスペクタービュー上側、Playerと書いてある左側のチェックボックスをクリック

ステージを描画しよう

ヒエラルキービューのStartStageを左クリックで選択
右側インスペクタービュー上側、StartStageと書いてある左側のチェックボックスをクリック

プレイヤーを動かそう

PlayerオブジェクトにPlayerInputスクリプトをアタッチ
プレイヤーが動くことを確認しよう

プレイヤーを前進させよう

Assetsフォルダ -> Scriptsフォルダ -> [PlayerInput]をダブルクリック
プレイヤーを前進させる処理を入力してみよう

プレイヤーにアニメーションをつけよう

Assetsフォルダ -> Scriptsフォルダ -> [PlayerInput]をダブルクリック
プレイヤーのアニメーションを再生する処理を入力してみよう

カメラでプレイヤーを追いかけよう

ヒエラルキーウィンドウ [PlCamera] を選択
CameraControllerスクリプトのプレイヤーオブジェクトに ヒエラルキービューからPlayerをドラッグ＆ドロップ

障害物を設置しよう

Assetsフォルダ -> Prefabsフォルダ -> [タル]をヒエラルキービューにドラッグ＆ドロップ
インスペクタービューのTransformのPositionを [ x : 1 , y : 0.75 , z : 15 ] に変更しよう

当たり判定をつけよう

Assetsフォルダ -> Scriptsフォルダ -> [HitCheck]をダブルクリック
プレイヤーが障害物に当たったときの判定を入力してみよう

プレイヤーの移動速度を調節しよう

PlayerのインスペクタービューのPlayerMoveスクリプトの値を変更
遊びやすい移動速度とジャンプの高さに調節しよう

ステージを表示しよう

ヒエラルキービューのStartStageを選択してインスペクタービューのチェックを外す

ヒエラルキービューのStageGeneratorを選択してインスペクタービューのチェックをつける

アイテム(にんじん)を集めよう

ヒエラルキービューのPlayer左側 「▶」 を押して広げる
Playerの下にあるItemGetCheckerを左クリックで選択
右側インスペクタービュー上側、ItemGetCheckerと書いてある左側のチェックボックスをクリック

無限生成ステージを作ろう

ヒエラルキービューのStageGeneratorを選択して、StageManagerスクリプト
ステージの登録の「+」を4回押す
Assetsフォルダ -> Prefabsフォルダ -> StagePrefabs -> Stage_0 ～ Stage_3をアタッチ

UIを描画しよう

ヒエラルキービューのCanvasを選択してインスペクタービューのチェックをつける

リトライ機能を実装しよう

見た目を良くしよう -衝突時エフェクトを出そう-
